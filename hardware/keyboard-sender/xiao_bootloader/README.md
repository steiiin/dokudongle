# XIAO nRF52840 Bootloader Preparation

This document describes how to build and install a customized OTAFIX bootloader for the **Seeed Studio XIAO nRF52840 BLE**.

The customized bootloader changes the BLE name shown while the device is in OTA/DFU mode from `XIAO_DFU` to:

```text
DOKUDONLGE_OTA
```

## 1. Build the bootloader

### Clone the bootloader repository

Clone the OTAFIX bootloader repository including all submodules:

```bash
git clone --recursive https://github.com/oltaco/Adafruit_nRF52_Bootloader_OTAFIX.git
cd Adafruit_nRF52_Bootloader_OTAFIX
```

### Change the OTA device name

Open the board configuration:

```bash
nano src/boards/xiao_nrf52840_ble/board.mk
```

Change:

```make
CFLAGS += -DDEVICE_NAME='"XIAO_DFU"'
```

to:

```make
CFLAGS += -DDEVICE_NAME='"DOKUDONLGE_OTA"'
```

### Build the bootloader

Build for the XIAO nRF52840 BLE:

```bash
make BOARD=xiao_nrf52840_ble all
```

The generated files are located in:

```text
_build/build-xiao_nrf52840_ble/
```

The `.zip` file contains the bootloader and the S140 SoftDevice and can be used for serial DFU flashing.

### Copy the bootloader package

Create the destination directory if necessary:

```bash
mkdir -p XIAO_bootloader
```

Copy the generated DFU package:

```bash
cp _build/build-xiao_nrf52840_ble/*.zip XIAO_bootloader/
```

The resulting directory should contain a file similar to:

```text
XIAO_bootloader/
└── xiao_nrf52840_ble_bootloader-<version>_s140_7.3.0.zip
```

---

## 2. Install the bootloader

The `.zip` package can be flashed using a compatible Arduino/DFU tool or directly with `adafruit-nrfutil`.

Connect the XIAO nRF52840 via USB and determine its serial port, for example:

```text
/dev/ttyACM0
```

Flash the bootloader package with:

```bash
adafruit-nrfutil --verbose dfu serial \
    --package xiao_nrf52840_ble_bootloader-0.9.2-OTAFIX2.3-BP1.4-2-g3a75482-dirty_s140_7.3.0.zip \
    -p /dev/ttyACM0 \
    -b 115200 \
    --singlebank \
    --touch 1200
```

Replace:

```text
<version>
```

with the actual filename generated by the build.

Alternatively, select the generated `.zip` from the `XIAO_bootloader` directory when using a compatible ArduinoTools DFU flashing function.

## Notes

This build target is specifically for:

```text
xiao_nrf52840_ble
```

For a XIAO using the **Sense bootloader**, use the `xiao_nrf52840_ble_sense` target instead.

The installed bootloader variant can be checked by entering UF2 mode and inspecting `INFO_UF2.TXT`.

Normal XIAO:

```text
Board-ID: nRF52840-SeeedXiao-v1
```

XIAO Sense:

```text
Board-ID: nRF52840-SeeedXiaoSense-v1
```
